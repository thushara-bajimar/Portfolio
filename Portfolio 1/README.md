# Thushara B S — Portfolio

A simple personal portfolio webpage introducing Thushara B S. It is built with plain HTML and CSS, with a soft pink color palette and a layout that adapts for narrow screens.

## Preview

Open `index.html` in a browser to view the portfolio. No build step, package installation, or server is required.

## Features

- Personal introduction and name header
- Fixed top navigation-style header
- Responsive header adjustments for small screens
- Styling kept separate from the page markup

> The Home and Contact labels are currently visual elements, not linked navigation controls.

## Project structure

```text
Portfolio 1/
├── index.html   # Page content and metadata
├── style.css    # Layout, colors, and responsive styles
├── script.js    # Currently empty; reserved for future interactions
├── README.md    # Project documentation
└── assets/      # Reserved for images and other static assets
```

## Run locally

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in your browser.

For a convenient editing workflow, open the folder in Visual Studio Code and use a local static-server extension if you want browser auto-refresh while editing.

## Customize

- Update the page title and introductory text in `index.html`.
- Change colors, spacing, and responsive styles in `style.css`.
- Add images or other files to `assets/`, then reference them from the HTML or CSS.
- Add JavaScript to `script.js` only when interactive behavior is needed; include it in `index.html` with a script tag.
