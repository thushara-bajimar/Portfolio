# Thushara B S — Portfolio Projects

This repository contains two versions of a personal portfolio website. Each version is maintained in its own folder and can be run independently.

## Projects

| Folder | Description | Technologies | Instructions |
| --- | --- | --- | --- |
| [Portfolio 1](Portfolio%201/) | Lightweight introductory page with a pink theme. | HTML, CSS | [Portfolio 1 README](Portfolio%201/README.md) |
| [Portfolio 2](Portfolio%202/) | Portfolio prototype with an intro section, an about section, and skill tags. | Next.js, React, Tailwind CSS | [Portfolio 2 README](Portfolio%202/README.md) |

## Choose a version

- For a simple static page with no installation or build step, open `Portfolio 1/index.html` in a browser.
- For the Next.js version, follow the setup and run instructions in [Portfolio 2 README](Portfolio%202/README.md).

## Repository layout

```text
.
├── Portfolio 1/   # Standalone HTML/CSS portfolio
└── Portfolio 2/   # Next.js portfolio application
```

The two projects are independent. Install dependencies and run development commands from inside `Portfolio 2`, not from the repository root.
